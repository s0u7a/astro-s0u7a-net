# s0u7a.net

Personal website — [s0u7a.net](https://s0u7a.net)

Built with [Astro](https://astro.build) + Tailwind CSS, deployed on Cloudflare.

## Stack

- Astro 4 / TypeScript
- Tailwind CSS
- Cloudflare Pages

## Development

```bash
npm install
npm run dev      # local dev
npm run build    # production build
npm run preview  # preview build
```
